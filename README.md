# TTK_WL_BOT Setup

## Install
Upload this project to GitHub then deploy on Railway.

## Railway Variables

DISCORD_TOKEN=your_bot_token
WL_ROLE_ID=your_role_id
WL_ROLE_NAME=Wl
WL_CHANNEL_ID=

## Discord Developer Portal
Enable:
- Message Content Intent
- Server Members Intent

## Start
Railway will run:
npm install
npm start
